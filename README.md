# ⛄ Abominable Snowman Animation

A fun and creative **CSS animation project** featuring an animated Abominable Snowman.  
This project focuses on **pure CSS animations** .Practicing CSS GSAP library, visual storytelling, and playful UI design without using JavaScript frameworks.

## 📌 Project Overview
The **Abominable Snowman Animation** is a front-end visual project designed to practice and showcase **CSS animation techniques**.  
It brings a character to life using only HTML and CSS, emphasizing creativity, timing, and smooth motion.

This project highlights how powerful CSS can be when used intentionally.

---

## ✨ Key Features
- Smooth CSS-based animations  
- Character animation effects  
- Clean and lightweight structure  
- No JavaScript required  
- Responsive layout  
- Creative and playful UI
